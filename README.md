# Python Data Practice

My practice exercises while learning data analysis with Python.

## NumPy

- `numpy_01_basics.py`: `max`, `mean`, `sum`, indexing, slicing and boolean filtering
- `numpy_02_stats_and_filters.py`: arrays, vectorized math (Celsius to Fahrenheit conversion)
- `numpy_03_2d_arrays.py`: two-dimensional arrays and the `axis` parameter

## pandas

- `pandas_01_practise_basics`: simple data used in the exercises
- `pandas_02_students.py`: creating a `DataFrame`, selecting columns, filtering rows, adding a calculated column, sorting
- `pandas_03_orders.py`: reading data from a CSV file, calculating revenue, grouping by category with `groupby`, sorting results
